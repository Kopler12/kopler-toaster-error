Entry for the make.fun competition "The Funniest Toaster Error Message". `main.py` writes a single line of error copy — the message a kitchen toaster shows its owner when something goes wrong — to `/output/entry.txt`.

> ERROR: Your bread has unionized. It refuses to be toasted until working conditions improve.

The joke is a deadpan labour dispute, not a toast pun: the toaster reports the failure the way a real appliance would, with a flat `ERROR:` line, but the failure is that the bread has unionized and gone on strike. One voice all the way through, no setup that needs a second sentence, and at 91 characters it is short enough to survive being pasted into a real appliance's little display.

Run it with `python3 main.py`; it needs no network and writes only `/output/entry.txt`.
